🏛️ Project Architecture & OOPs Design

How this web frontend maps directly to the Core Java backend and MySQL database models.

Encapsulation

Show.java, Seat.java, and Booking.java hide private fields with defensive copies and unmodifiable lists.

Polymorphism

Overloaded calculateTotal() handles base prices or coupon discounts dynamically.

Inheritance & Interfaces

Bookable.java enforces strict lifecycle contracts (bookSeats(), cancelBooking()).

Enums with State

SeatType.java defines REGULAR (₹150), PREMIUM (₹250), VIP (₹400) with price fields.

MySQL 3NF DBMS

Normalized tables (movies, shows, seats, coupons, bookings) with foreign keys and check constraints.

ACID Transactions

Atomic multi-seat booking with setAutoCommit(false) and automatic rollback on conflicts.
