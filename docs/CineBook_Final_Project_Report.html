Abstract

The CineBook - Movie Ticket Booking System is an enterprise-grade console application engineered in Java (JDK 17+) and backed by a relational MySQL 8.0 database via the Java Database Connectivity (JDBC) API. The project bridges theoretical Object-Oriented Programming (OOP) paradigms with practical Relational Database Management System (DBMS) principles.

Key OOP principles demonstrated include Encapsulation, Polymorphism (overloaded calculateTotal()), Inheritance & Interfaces (Bookable interface implementation), and Enums (SeatType binding categories to prices). Key DBMS principles include a normalized 3NF schema, ACID transactional boundaries (setAutoCommit(false), commit(), and rollback()), and parameter-bound PreparedStatement queries guaranteeing SQL injection immunity.

Chapter 1: Introduction

Modern movie entertainment complexes require robust booking infrastructure capable of managing seating availability, multi-tier pricing, promotional campaigns, and transaction cancellations in real time. The CineBook system is developed to automate the box-office ticketing desk of a multiplex cinema. Built in core Java and interfaced with MySQL, it provides cinema administrators and ticketing operators with a responsive, menu-driven command-line interface.

Chapter 2: Requirements and Feasibility

CineBook satisfies all specified functional requirements (FR-1 through FR-8), including live $5 \times 8$ seat map rendering, multi-seat reservation, tiered pricing via enums (Regular: ₹150, Premium: ₹250, VIP: ₹400), coupon validation with 10% discount, and 80% refund processing on cancellation.

Chapter 4: Database Design

The system utilizes MySQL 8.0 with the InnoDB storage engine for transactional integrity. Tables implemented:

  • movies: Master catalog of movie titles, runtimes, and genres.
  • shows: Screenings with foreign keys to movies.
  • seats: All 40 seats per show tracking live boolean availability flags.
  • coupons: Promotional discount codes with percentage deduction rules.
  • bookings: Complete audit ledger tracking booking IDs, amounts, and cancellation statuses.
  • booking_seats: 1NF normalized bridge table linking bookings to reserved seats.

Chapter 5: Implementation

The implementation combines Java SE 17+ and the official MySQL Connector/J JDBC driver. Full CRUD operations are implemented:

  • CREATE: Atomic insert into bookings and seat status updates guarded by transactions.
  • READ: Queries fetching available shows, live seat grids, and booking records.
  • UPDATE: Cancellation updates resetting booking status to CANCELLED and freeing reserved seats.
  • DELETE: Administrative record cleanup while maintaining soft-delete status for audit compliance.
